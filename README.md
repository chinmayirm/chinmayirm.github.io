# The Digital Guild of Chinmayi

Interactive museum-style portfolio for GitHub Pages (`chinmayirm.github.io`).

## Quick start

1. Replace images in `assets/` (see list below).
2. Open `index.html` locally, or deploy:

```bash
# Create repo named chinmayirm.github.io, then:
git init
git add .
git commit -m "Launch Digital Guild portfolio"
git branch -M main
git remote add origin https://github.com/chinmayirm/chinmayirm.github.io.git
git push -u origin main
```

Then enable **Settings → Pages → Deploy from branch → main**.

## Images you need

Put these files in `assets/` (placeholders are already downloaded; swap for your own):

| File | What to use | Tips |
|------|-------------|------|
| `portrait.jpg` | **Your photo / painted portrait** | Vertical ~3:4. Classical or studio lighting. This is the gold-frame hero. |
| `hero-oil.jpg` | Muted high-contrast oil painting / ink landscape | Full-bleed hero backdrop. Met Open Access or Unsplash “oil painting dark”. |
| `manuscript.jpg` | Weathered parchment / aged paper texture | Soft, low contrast; used behind The Codex. |
| `project-gliner.jpg` | Autosuggest / NER / travel-search visual | Dashboard mock, entity tags, or abstract NLP. |
| `project-yoda.jpg` | Chatbot / Star Wars–adjacent or dialogue UI | Screenshot or atmospheric still. |
| `project-chroma.jpg` | Colour spectrum / accessibility / CV | Vibrant colour study (hover reveals full colour). |
| `project-isro.jpg` | Satellite / Earth from space / farmland from above | Matches ISRO remote sensing work. |
| `project-qvit.jpg` | Quantum / abstract circuits / neural geometry | For Quantum ViT. |
| `project-compress.jpg` | Abstract image compression / glitch art | PCA/SVD project. |
| `project-airbnb.jpg` | Interior / city listings aesthetic | Airbnb EDA. |
| `project-rag.jpg` | Maps, UN/global politics, network graphs | Geopolitical RAG system. |
| `gallery-1.jpg` … `gallery-6.jpg` | Oriental / classical gallery pieces | Varied heights; ink wash, temples, peonies, silk, lacquer, misty mountains. |

### Recommended free sources

- [The Met Open Access](https://www.metmuseum.org/art/collection) — Japanese screens, Chinese landscapes, gold lacquer
- [Unsplash](https://unsplash.com) — search: `japanese temple`, `ink wash`, `oil painting dark`, `parchment`
- [Wikimedia Commons](https://commons.wikimedia.org) — public domain oriental art
